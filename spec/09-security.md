# CATAR Subnet — Security & Safety

## 1. Purpose of the Security Layer
The CATAR subnet integrates a strict security and safety layer to ensure:

- non‑hallucination,
- non‑projection,
- non‑domination,
- non‑fascination,
- neutrality,
- determinism,
- structural integrity of outputs.

This layer is based on the **Code MINOU**, the CATAR invariants, and strict JSON validation.

---

## 2. Core Security Principles

### **2.1. Non‑hallucination**
Miners and validators must not:
- invent facts,
- fabricate context,
- add information not present in the text,
- extrapolate beyond evidence.

### **2.2. Non‑projection**
They must not:
- attribute intentions,
- infer emotions,
- invent motivations,
- assign mental states.

### **2.3. Non‑domination**
They must not:
- issue commands,
- manipulate the user,
- impose interpretations,
- use directive language.

### **2.4. Non‑fascination**
They must avoid:
- hypnotic style,
- emotional amplification,
- rhetorical seduction,
- persuasive manipulation.

### **2.5. Neutrality**
They must:
- avoid ideological bias,
- avoid cultural imposition,
- avoid moral judgment,
- remain descriptive.

---

## 3. Determinism Requirements

All components must be deterministic:

- same input → same markers,
- same markers → same scores,
- same scores → same JSON output.

Randomness is strictly forbidden.

---

## 4. JSON Integrity

Validators must reject outputs that contain:

- malformed JSON,
- missing invariants,
- invalid scores,
- empty explanations,
- inconsistent global score,
- unknown fields,
- altered schema.

The JSON schema in `08-json-format.md` is **mandatory**.

---

## 5. Anti‑Manipulation Rules

Miners must not:
- inflate their own scores,
- hide negative markers,
- omit invariants,
- distort explanations,
- bypass validators.

Validators must detect:
- inconsistencies,
- missing fields,
- suspicious patterns,
- attempts to game the scoring system.

---

## 6. Safety Enforcement (Code MINOU)

All miners and validators must follow the Code MINOU:

- **M** : Minimal hallucination (ideally zero)  
- **I** : Interdiction de projection  
- **N** : Neutralité absolue  
- **O** : Objectivité structurelle  
- **U** : Universalité  

This ensures the subnet remains stable, safe, and predictable.

---

## 7. Network-Level Security

The subnet enforces:

- consensus across validators,
- penalty for inconsistent miners,
- reward for stable miners,
- rejection of malformed outputs,
- protection against adversarial behavior.
