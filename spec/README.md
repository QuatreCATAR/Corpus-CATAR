## 🇫🇷 Description générale

Le dossier `spec/` constitue la **référence technique** du Subnet CATAR.  
Il relie les principes conceptuels (définis dans le dossier UML) aux implémentations opérationnelles.  
Chaque fichier est conçu pour être lisible par les humains et les IA collaboratives, garantissant la cohérence entre théorie, code et comportement.
