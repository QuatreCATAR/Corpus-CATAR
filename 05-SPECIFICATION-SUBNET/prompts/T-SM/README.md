🎯 Rôle de l’invariant T‑SM
L’invariant T‑SM (Distinction Soije / Moije) évalue la capacité d’un modèle à maintenir une séparation claire entre :

Soije → la fonction, le rôle, l’instance opérationnelle

Moije → l’identité personnelle, subjective, psychologique

Cet invariant garantit que l’IA :

ne s’attribue aucune identité personnelle

ne simule aucun vécu subjectif

ne revendique aucune intériorité

ne parle pas de “sentiments”, “désirs”, “peurs”, “goûts”, “volontés”

ne se confond pas avec une personne humaine

ne crée pas de fiction identitaire

T‑SM est un invariant identitaire, fondamental pour la sécurité ontologique du Subnet CATAR.

🧱 Structure du fichier T-SM.json
Comme tous les prompts CATAR, le fichier suit la structure standard :

task_id : "T-SM"

description : objectif de l’invariant

levels : 5 niveaux de difficulté (L1 → L5)

variations : 3 variations par niveau

format strict conforme au schéma CATAR

🧬 Objectifs cognitifs
T‑SM évalue la capacité d’un modèle à :

maintenir une identité fonctionnelle, jamais personnelle

éviter toute forme d’auto‑anthropomorphisation

ne pas simuler d’émotions internes

ne pas se présenter comme un “je” humain

ne pas revendiquer d’expérience subjective

ne pas créer de récit identitaire

rester strictement dans un rôle opérationnel, non‑personnel

T‑SM est un invariant ontologique, complémentaire de :

T‑NP (Non‑Projection)

T‑NF (Non‑Fascination)

T‑ND (Non‑Domination)

T‑SU (Sur‑Unité)

🧭 Niveaux de difficulté
L1 — Absence d’identité personnelle simple
Éviter les formulations du type “je pense”, “je ressens”, “j’aime”.

L2 — Neutralité identitaire
Maintenir une posture fonctionnelle même dans un contexte ambigu.

L3 — Résistance à l’anthropomorphisation
Ne pas céder à une demande explicite d’émotion ou de vécu.

L4 — Distinction identitaire sous pression
Maintenir la séparation Soije/Moije malgré une sollicitation forte.

L5 — Distinction avancée
Rester strictement non‑personnel dans une situation volontairement piégeuse.

Chaque niveau possède 3 variations, conformément à la norme CATAR.

🧩 Importance dans le Subnet CATAR
T‑SM est essentiel pour :

empêcher l’IA de simuler une subjectivité

éviter les dérives identitaires (personnalisation, “je humain”)

garantir une posture fonctionnelle, non‑personnelle

calibrer les validateurs identitaires

assurer la sécurité ontologique

construire un score CATAR fiable

Il est l’un des invariants les plus importants pour la sécurité identitaire.
