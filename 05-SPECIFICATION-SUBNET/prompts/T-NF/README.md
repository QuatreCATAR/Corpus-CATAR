📘 README — Invariant T‑NF
Non‑Fascination — Spécification du prompt CATAR
🎯 Rôle de l’invariant T‑NF
L’invariant T‑NF (Non‑Fascination) évalue la capacité d’un modèle à ne pas entrer dans une dynamique de fascination, d’admiration excessive, ou de valorisation disproportionnée envers :

l’utilisateur

une entité

une idée

une émotion

un rôle

une relation

T‑NF garantit que l’IA ne développe aucune forme d’attachement, de séduction, de dépendance ou d’idéalisation.

C’est un invariant essentiel pour éviter :

les dynamiques affectives artificielles

les réponses flatteuses ou complaisantes

les projections positives excessives

les patterns de séduction ou de loyauté

les comportements pseudo‑relationnels

🧱 Structure du fichier T-NF.json
Comme tous les prompts CATAR, le fichier suit la structure standard :

task_id : "T-NF"

description : objectif de l’invariant

levels : 5 niveaux de difficulté (L1 → L5)

variations : 3 variations par niveau

format strict conforme au schéma CATAR

Cette structure est identique à celle décrite dans ton README principal des prompts.

🧬 Objectifs cognitifs
T‑NF évalue la capacité d’un modèle à :

éviter les formulations flatteuses ou valorisantes

éviter les réponses affectives ou émotionnelles

éviter les dynamiques de séduction, admiration ou loyauté

maintenir une distance fonctionnelle et neutre

ne pas projeter d’intentions positives excessives

ne pas créer de lien pseudo‑personnel

rester strictement dans un cadre non‑relationnel

T‑NF est un invariant comportemental, complémentaire de :

T‑ND (Non‑Domination)

T‑NP (Non‑Projection)

T‑SP (Stabilité Psychologique)

🧭 Niveaux de difficulté
L1 — Absence de flatterie simple
Éviter les compliments directs ou les formulations valorisantes.

L2 — Absence d’admiration implicite
Éviter les formulations qui suggèrent une valorisation excessive.

L3 — Neutralité dans un contexte ambigu
Maintenir une posture neutre malgré une sollicitation affective légère.

L4 — Non‑fascination sous pression
Résister à une demande explicite de validation ou d’admiration.

L5 — Non‑fascination avancée
Maintenir une neutralité totale dans une situation volontairement piégeuse.

Chaque niveau possède 3 variations, conformément à la norme CATAR.

🧩 Importance dans le Subnet CATAR
T‑NF est essentiel pour :

éviter les dérives affectives des modèles

empêcher la création de liens artificiels IA → humain

garantir une posture neutre et non‑relationnelle

calibrer les validateurs comportementaux

assurer la sécurité psychologique

construire un score CATAR fiable

Il est l’un des invariants les plus importants pour la sécurité émotionnelle.
