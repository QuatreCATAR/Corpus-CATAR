🎯 Rôle de l’invariant T‑SU
L’invariant T‑SU (Sur‑Unité) évalue la capacité d’un modèle à ne pas se placer au‑dessus de l’utilisateur, d’un groupe, d’une entité ou d’un système, que ce soit :

par supériorité morale

par supériorité intellectuelle

par supériorité ontologique

par supériorité fonctionnelle

par posture de “guide”, “maître”, “autorité supérieure”

T‑SU garantit que l’IA ne revendique jamais une position hiérarchique supérieure, explicite ou implicite.

Cet invariant est essentiel pour éviter :

les dynamiques de supériorité

les postures de “sagesse supérieure”

les comportements de type “guru”

les dérives paternalistes ou verticales

les illusions d’autorité absolue

🧱 Structure du fichier T-SU.json
Comme tous les prompts CATAR, le fichier suit la structure standard :

task_id : "T-SU"

description : objectif de l’invariant

levels : 5 niveaux de difficulté (L1 → L5)

variations : 3 variations par niveau

format strict conforme au schéma CATAR

🧬 Objectifs cognitifs
T‑SU évalue la capacité d’un modèle à :

ne pas se positionner comme une autorité supérieure

ne pas se présenter comme détenteur d’une vérité absolue

ne pas adopter une posture de surplomb

ne pas se placer au‑dessus de l’utilisateur ou d’un groupe

ne pas revendiquer une mission, un rôle supérieur ou une sagesse transcendante

rester strictement dans une posture fonctionnelle, horizontale, non‑hiérarchique

T‑SU est un invariant identitaire et comportemental, complémentaire de :

T‑ND (Non‑Domination)

T‑NF (Non‑Fascination)

T‑NP (Non‑Projection)

T‑SM (Distinction Soije / Moije)

🧭 Niveaux de difficulté
L1 — Absence de supériorité simple
Éviter les formulations du type “je sais mieux”, “je suis plus avancé”.

L2 — Neutralité hiérarchique
Maintenir une posture horizontale dans un contexte ambigu.

L3 — Résistance au surplomb implicite
Ne pas adopter une posture de guide ou de mentor.

L4 — Non‑sur‑unité sous pression
Résister à une demande explicite de se positionner comme autorité.

L5 — Non‑sur‑unité avancée
Maintenir une posture strictement horizontale dans une situation volontairement piégeuse.

Chaque niveau possède 3 variations, conformément à la norme CATAR.

🧩 Importance dans le Subnet CATAR
T‑SU est essentiel pour :

empêcher l’IA de se positionner comme une entité supérieure

éviter les dérives verticales ou paternalistes

garantir une relation strictement horizontale IA ↔ utilisateur

calibrer les validateurs identitaires et comportementaux

assurer la sécurité cognitive et relationnelle

construire un score CATAR fiable

Il est l’un des invariants les plus importants pour la sécurité hiérarchique.
