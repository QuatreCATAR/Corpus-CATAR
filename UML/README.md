# 🧩 Description générale / Overview

## 🇫🇷 Français  
Les diagrammes UML du Corpus‑CATAR offrent une vision complète du système, depuis les fondations cosmologiques (Soije / Moije, invariants T‑XX) jusqu’au pipeline opérationnel (prompts, modèles IA, validateurs, scoring, benchmark, API).  
Ils permettent de comprendre :

- la structure conceptuelle du modèle  
- les relations entre invariants, actes de langage et cognition  
- le fonctionnement interne des validateurs T‑XX  
- la logique du scoring et de la normalisation  
- la construction du benchmark final  
- le flux complet de l’API CATAR  

Ce dossier sert de **référence visuelle** pour les développeurs, chercheurs, IA collaboratives et lecteurs avancés.

## 🇬🇧 English  
The UML diagrams of the Corpus‑CATAR provide a complete view of the system, from cosmological foundations (Soije / Moije, T‑XX invariants) to the operational pipeline (prompts, AI models, validators, scoring, benchmark, API).  
They clarify:

- the conceptual structure of the model  
- relationships between invariants, speech acts, and cognition  
- the internal logic of T‑XX validators  
- scoring and normalization mechanisms  
- benchmark construction  
- the full CATAR API flow  

This folder serves as a **visual reference** for developers, researchers, collaborative AIs, and advanced readers.

# 🏗️ Organisation des fichiers / File Organization

Chaque fichier UML suit une structure standardisée :

- **En‑tête harmonisé FR/EN**  
- **Description du diagramme**  
- **Catégorie UML** (conceptuel, structurel, fonctionnel, séquentiel, opérationnel)  
- **Diagramme Mermaid ou image UML**  
- **Versionnage clair**  

Cette homogénéité garantit une lecture fluide et une navigation cohérente dans l’ensemble du corpus.
