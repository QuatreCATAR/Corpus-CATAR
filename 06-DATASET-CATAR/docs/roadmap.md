# 🗺️ Roadmap du Subnet CATAR  
*Version 1.0 — Vision stratégique & évolutions prévues*

Cette roadmap présente les évolutions prévues du Subnet CATAR, organisées en trois horizons :

- **Horizon 1 — Court terme (v1.x)**  
- **Horizon 2 — Moyen terme (v2.x)**  
- **Horizon 3 — Long terme (v3.x et au‑delà)**  

Elle sert de guide pour les mainteneurs, contributeurs et partenaires techniques.

---

# 1. Vision générale

CATAR vise à devenir :

- un **standard ouvert** d’évaluation cognitive  
- un **outil de sécurité** pour les IA  
- un **référentiel universel** pour la neutralité, la cohérence et la non‑domination  
- un **benchmark reproductible** pour comparer les modèles  

La roadmap reflète cette ambition.

---

# 2. Horizon 1 — Court terme (v1.x)

## 2.1 Stabilisation du Subnet
- finalisation des validateurs  
- stabilisation des pondérations  
- amélioration du scoring  
- validation croisée des invariants  

## 2.2 Amélioration du dataset
- ajout de nouveaux prompts T‑XX  
- enrichissement des variations  
- amélioration du curated  
- nettoyage automatique  

## 2.3 API & outils
- API REST complète  
- documentation API enrichie  
- outils CLI supplémentaires  
- test_interactif amélioré  

## 2.4 Benchmark v1.1
- nouvelles visualisations  
- comparaison multi‑modèles  
- export CSV/JSON amélioré  

---

# 3. Horizon 2 — Moyen terme (v2.x)

## 3.1 CATAR‑Benchmark v2
- ajout de métriques avancées  
- analyse multi‑dimensionnelle  
- scoring probabiliste  
- heatmaps cognitives  

## 3.2 Dashboard interactif
- interface web  
- visualisation dynamique  
- filtres par invariant, modèle, niveau  
- export PDF/PNG  

## 3.3 Extension des invariants
- ajout d’invariants spécialisés  
- invariants contextuels (dialogue, long‑form, multimodal)  
- invariants temporels (cohérence sur plusieurs tours)  

## 3.4 Compatibilité multi‑modèles
- wrappers pour modèles open‑source  
- intégration HuggingFace  
- support multi‑GPU  

---

# 4. Horizon 3 — Long terme (v3.x et au‑delà)

## 4.1 CATAR‑OS
- version autonome du Subnet  
- exécutable local  
- API embarquée  
- sandbox cognitive  

## 4.2 CATAR‑Live
- évaluation en temps réel  
- monitoring continu  
- détection de dérives instantanée  

## 4.3 CATAR‑Training
- intégration dans les pipelines RLHF  
- rétroaction cognitive  
- apprentissage guidé par invariants  

## 4.4 Certification CATAR
- standardisation internationale  
- certification de modèles IA  
- conformité cognitive  

---

# 5. Priorités stratégiques

1. **Robustesse**  
   - validateurs fiables  
   - scoring stable  
   - dataset propre  

2. **Transparence**  
   - documentation complète  
   - API claire  
   - schémas publics  

3. **Interopérabilité**  
   - formats standard  
   - compatibilité HF  
   - API REST  

4. **Sécurité cognitive**  
   - non‑domination  
   - non‑projection  
   - cohérence logique
